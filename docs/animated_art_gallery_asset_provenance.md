# Animated Art Gallery Asset Provenance

The user requested that GIPHY be used to locate animated painting imagery for the **Animated Art Gallery** SpecialLock theme. The selected source pages and creator attributions displayed by GIPHY were the following: Van Gogh artwork by OtO (`@OtOarts`) at <https://giphy.com/gifs/OtOarts-vangogh-gogh-vincentvangogh-uPzhU1NKrzA5Whq1Gz>; Mona Lisa animation by systaime (`@systaime`) at <https://giphy.com/gifs/animation-art-history-joconde-WMnN9E23nEQbS59BKo>; Monet artwork from the Petit Palais / Paris Musées search result at <https://giphy.com/gifs/claude-monet-soleil-couchant-sur-la-seine-lavacourt-1880-petitpalais-parismusees-VhuOqgitgoEzWTJrn9>; and Hokusai artwork from GIF IT UP at <https://giphy.com/gifs/gifitup-art-ghost-spooky-Gk5OwkHo4K1Xi42Cdd>.

For device compatibility, ten evenly sampled frames from each user-requested GIPHY source were placed, without cropping the individual works, into an original 340 × 400 white gallery presentation with four small layered gilt frames. The resulting GIF loops on selection, stays below the remote asset size and decoded-frame budgets, and contains no executable content. It is downloaded only when the user selects the theme; it is not included in the Debian package.
