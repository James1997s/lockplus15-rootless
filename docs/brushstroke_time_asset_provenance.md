# Brushstroke Time asset provenance

The `paintbrush` asset in `themes/assets/brushstroke-time/paintbrush.png` is an original AI-generated transparent paintbrush cutout created for the SpecialLock **Brushstroke Time** theme. It was then deterministically resized to 360 × 240 pixels and retained as a PNG with alpha for bounded local display.

The asset has no external source URL, does not represent a downloaded third-party artwork, and is fetched only as part of the user-selected theme’s normal asset download. The renderer never performs remote image or code loading; it resolves the already downloaded, SHA-256-verified asset from the SpecialLock theme cache.
